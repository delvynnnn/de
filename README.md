# Delvyn Vederick Portfolio

Portfolio personal berbasis Next.js, TypeScript, Tailwind CSS, Framer Motion, Lenis, dan next-themes. Konten personal berasal dari CV yang diberikan; proyek, testimoni, sosial media, peta, WhatsApp, serta form pengiriman tidak ditambahkan karena datanya tidak tersedia.

## Menjalankan secara lokal

1. Install Node.js 20 atau yang lebih baru.
2. Ekstrak ZIP ini dan buka folder proyek di terminal.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka `http://localhost:3000`.

## Build produksi

Jalankan `npm run build`, lalu `npm start`.

## Catatan

- Tombol email membuka aplikasi email melalui `mailto:`.
- Tombol telepon membuka aplikasi telepon melalui `tel:`.
- Form kontak tidak ditampilkan karena belum ada layanan/backend penerima pesan yang dikonfigurasi.
- Alamat hanya ditampilkan sebagai teks. Google Maps dan WhatsApp tidak dibuat tanpa tautan/data yang tersedia.
- Tidak ada proyek atau testimoni fiktif.
